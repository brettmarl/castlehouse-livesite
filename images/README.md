# Image assets

Organised by provenance so that authentic and illustrative imagery are never confused:

| Folder       | Contents                                                                 | Labelled on site as      |
|--------------|---------------------------------------------------------------------------|--------------------------|
| `property/`  | Authentic photographs of Castle House (family-owned or permissioned only) | —                        |
| `archive/`   | Historic family photos, B&B brochures, guestbook pages                    | "Archive"                |
| `chester/`   | Photographs of Chester (licensed)                                         | —                        |
| `concept/`   | Inspirational / illustrative interiors — never the actual house           | "Concept · Illustrative" |

After adding a file, register it in `src/content/images.ts` by setting `src` on the relevant entry.

Recommended: JPEG/WebP, longest edge 2400px for full-bleed images and 1600px for others,
with smaller `srcSet` variants (e.g. 800w / 1600w / 2400w). Keep each file under ~400 KB.

Note: photographs from the estate agent listing are not automatically licensed for reuse — obtain permission first.
